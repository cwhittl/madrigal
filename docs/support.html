Support

Answers to common questions. If something isn't covered here, open an issue on GitHub.

Getting started

How do I add a provider?

Open Settings (the gear in the sidebar, or ⌘, on Mac), tap Add Provider, and pick a preset. Paste your API key, tap Fetch models, choose a model, then close Settings and start a chat. Keys come from each provider's own dashboard, for example platform.openai.com or openrouter.ai/keys.

Do I need to pay for an AI service?

Not necessarily. Apple Intelligence (on supported devices with iOS 26 or macOS 26 and later) and downloaded on-device models are free and need no key. Hosted providers bill you directly, through your own account, for what you use.

How do I set up Cloudflare Workers AI?

Pick the Cloudflare Workers AI preset. It asks for:

  • Account ID: 32 hexadecimal characters, shown in the Cloudflare dashboard sidebar or in the URL of your account overview page.
  • API token: create one under My Profile → API Tokens with the Workers AI: Read permission. This is not your Global API Key.

Fetch models lists Cloudflare's text-generation models. You can also type a model ID such as @cf/meta/llama-3.1-8b-instruct.

Can I use LM Studio, Ollama or my own server?

Yes. Use the LM Studio or Ollama preset, or Custom for any OpenAI-compatible endpoint. On iPhone and iPad, localhost means the device itself, so enter your computer's local IP address (for example http://192.168.1.20:1234/v1) and allow connections from the local network in the server's settings.

On-device models

How do I run a model on my device?

Add the On-device models (MLX) provider and download a model from the list. Each model is rated against your device's memory as Recommended, May be slow or unstable, or needing more memory than the device has. Models run on Apple silicon iPhones, iPads and Macs, and work offline once downloaded.

Why did a reply stop when I left the app?

On iOS 26 and later, replies keep going in the background, with progress shown by the system. On-device replies move to the slower CPU while the app is in the background, except on iPads that allow background GPU work. On earlier versions of iOS, replies stop shortly after you leave the app; use Regenerate to try again.

Can on-device models search the web?

Yes. Turn on Web search in the provider's settings. By default, queries go from your device to DuckDuckGo and Wikipedia. You can also use the Brave Search API with your own key, or a SearXNG server you run. A reply lists its sources below the text.

Sync and data

How does sync work?

Chats, projects, agents and providers sync through your private iCloud database to every device signed in to the same Apple Account. API keys sync through iCloud Keychain. Make sure iCloud and iCloud Keychain are turned on in your device's settings. Downloaded models don't sync; download them on each device.

Can I export a chat?

Yes. Use the export button in a chat's toolbar to copy it as Markdown, share it, or save a Markdown file.

Where can I read what the app sends, and to whom?

In the app under Settings → Privacy → What gets sent, and where, or in the privacy policy.
