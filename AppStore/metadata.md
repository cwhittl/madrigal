### Description (4000)
```
Madrigal is a fast, native AI chat app for iPhone, iPad and Mac. Bring your own API keys for the services you already use, or run open models entirely on your device. There are no accounts, no subscriptions and no servers in between: your messages go straight from your device to the model you choose.

YOUR PROVIDERS, YOUR KEYS
• Presets for OpenAI, Anthropic, Google Gemini, OpenRouter, xAI, Groq, Mistral, DeepSeek, Together AI and Cloudflare Workers AI
• Any OpenAI-compatible endpoint, including LM Studio and Ollama on your own network
• Fetch each provider's model list, or type any model ID
• Keys are stored in the Keychain and sync through your iCloud Keychain

ON-DEVICE MODELS
• Chat with Apple Intelligence on supported devices
• Download open models such as Qwen3, Gemma 3 and Llama 3.2 and run them privately with MLX
• Each model is rated against your device's memory before you download it
• Works offline once a model is downloaded
• Optional web search for on-device models, with sources listed under each reply

PROJECTS AND AGENTS
• Group related chats into projects with shared instructions and knowledge files (text, Markdown, PDF and more)
• Chats in a project can share short summaries, so each one knows what the others covered
• Save agents: a model with its own instructions, temperature and limits, picked like any other model

BUILT FOR READING AND WRITING
• Rich Markdown with headings, lists, tables and syntax-friendly code blocks
• Reasoning models show their thought process in a collapsible section
• Stop, retry, regenerate and edit messages
• Search across every chat
• Pin favorites, rename chats and move them between projects
• Copy, share or export any chat as Markdown

NATIVE ON EVERY DEVICE
• SwiftUI on iPhone, iPad and Mac, with keyboard shortcuts and a menu bar on Mac
• Chats, projects and agents sync through your private iCloud database
• On iOS 26 and later, replies keep streaming when you leave the app
• Light and dark appearance

PRIVATE BY DESIGN
Madrigal has no analytics, no ads and no tracking, and the developer never sees your chats or keys. A clear "Your Data" screen explains exactly what is sent, and where, before you start.

You need your own account and API key with a hosted provider, which bills you directly for what you use, or a device that supports Apple Intelligence or on-device models.
```
