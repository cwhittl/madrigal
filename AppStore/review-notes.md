# App Review notes

Paste the block below into App Store Connect → the version → App Review
Information → Notes. **Sign-in required: No** (leave the demo account fields empty).

Before submitting, replace `OPENROUTER_KEY_HERE` with a real OpenRouter key
created only for review, with a **credit limit of about $5**
(openrouter.ai → Keys → Create Key → Credit limit). Revoke it after approval.
Don't commit the real key; this file stays a template.

Contact: fill in your phone number and email in App Review Information.

```
Madrigal is a chat client for AI models. It has no accounts and no server of its own: users add their own AI provider with their own API key, or run models on the device. Nothing requires sign-in.

TO TEST WITH A HOSTED MODEL (any device):
1. Launch the app and tap "I Understand" on the "Your Data" screen. It explains what is sent to AI providers before anything is sent (Guideline 5.1.2(i)).
2. Tap the gear icon at the top of the sidebar (on Mac: Madrigal > Settings, or the gear in the sidebar).
3. Tap "Add Provider", then choose "OpenRouter".
4. Paste this key into the API Key field: OPENROUTER_KEY_HERE
   (A review-only key with a small spending limit.)
5. Tap "Fetch models", choose a model such as openai/gpt-4o-mini, then tap Done.
6. Close Settings, tap "New Chat", and send a message.

TO TEST WITHOUT A KEY:
- Apple Intelligence: on a device that supports Apple Intelligence (iOS 26 / macOS 26 or later, with Apple Intelligence turned on), choose "Apple Intelligence (on-device)" in Add Provider. No key needed.
- On-device models: choose "On-device models (MLX)" in Add Provider and download a small model, such as Llama 3.2 1B (about 0.7 GB). Requires Apple silicon; not available in the Simulator.

OTHER FEATURES:
- Projects: tap "+" next to Projects in the sidebar to add instructions and knowledge files shared by the project's chats.
- Agents: Settings > Add Agent saves a model with its own instructions.
- Web search (optional, on-device providers only, off by default): in the provider's settings.

AI-GENERATED CONTENT: replies are generated by the third-party model the user chooses (or by Apple's on-device model). The app doesn't ship or curate content. Hosted providers apply their own content policies. Users can copy, regenerate or delete any reply.

PRIVACY: the app collects no data. Requests go straight from the device to the provider the user picks. Chats sync only through the user's private iCloud database. API keys are stored in the Keychain. Privacy policy: https://cwhittl.github.io/madrigal/privacy.html (also linked in Settings > About and on the "Your Data" screen).

BACKGROUND MODES: "remote-notification" is used only for CloudKit sync pushes. On iOS 26, a reply that is still streaming when the user leaves the app continues as a BGContinuedProcessingTask with system-visible progress and a cancel button. Local notifications (asked for on first send) say when a reply that finished in the background is ready.
```
